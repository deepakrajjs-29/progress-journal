# Progress Journal 📖

A daily software engineering and computer science learning journal.

---

## 📌 Overview

A personal notebook documenting core technical mechanisms and principles across systems, programming, and architecture. Every entry is designed as a quick, high-density **1–3 minute read**.

---

## 📚 Topics Covered

- **[Programming](programming/)** — Fundamentals, data structures, and best practices.
- **[Git](git/)** — Internals, branching, and collaboration.
- **[Databases](databases/)** — SQL, data modeling, indexing, and transactions.
- **[Networking](networking/)** — Protocols, DNS, HTTP/HTTPS, and sockets.
- **[Web Architecture](web/)** — APIs, client-server models, and web fundamentals.
- **[Linux](linux/)** — Shell, permissions, process management, and tooling.
- **[Docker](docker/)** — Containers, images, and deployment basics.
- **[Security](security/)** — Authentication, authorization, and secure practices.
- **[Computer Science](computer-science/)** — Concurrency, memory models, and algorithms.

---

## 📝 Note Format

Each note follows a simple 4-part structure:

1. **Question** — The core mechanism or problem.
2. **Short Answer** — Concise, direct 2–5 sentence explanation.
3. **Simple Example** — Minimal code snippet or terminal command.
4. **Key Point** — The single most important takeaway.
